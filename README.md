A one-page household budget planner as plain static files, with the 50/30/20 guide, live totals, income percentages and a spending split bar. Data stays in the browser.

## Run it

Serve `app/` with any static server, then open `index.html`:

```sh
python3 -m http.server 8080 --directory app
```

Hand the site in (copies `app/` and `screenshots/` to the output dir and writes `dossier.json`):

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
